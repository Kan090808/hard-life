# 平衡性檢查筆記

## 目的

用固定種子的啟發式策略跑 500 局，快速看目前 MVP 是否「幾乎必輸」或「隨便都會贏」。

## 執行方式

```bash
node scripts/balance-check.mjs
```

## 目前觀察

- 這個版本仍然偏辛苦，符合題材。
- 在調整事件池前，粗略模擬幾乎都會死在過勞或欠租。
- 調整後加入 2 個偏正向事件、降低幾個高傷害事件的懲罰尖峰，讓粗略模擬開始出現可觀察的成功結局，而不是單純一路崩掉。
- 目前比較常見的存活結局是「窮忙循環」與少量「轉職成功」，表示核心取捨仍然成立，但後續仍值得再做玩家實測。

## 後續建議

- 真機遊玩幾輪，確認玩家是否能理解何時該休息、何時該先投資技能。
- 如果玩家普遍在第 2 次房租前就斷線，可以再補 1 到 2 個低傷害、偏回復的生活事件。
- 如果玩家太容易靠保守玩法穩定通關，再提高中後期事件的壓力或降低正向事件收益。
