# 平衡性檢查筆記

## 目前版本

- 一局 21 天，每天固定早上、下午、晚上三次決策。
- 模擬策略會根據現金、體力、壓力與技能選擇當下分數最高的行動。
- 固定種子跑 500 局，用來檢查是否必勝、必敗或只有單一結局。

## 2026-06-13 結果

- 通關率：32.4%
- 平均最終金錢：$821
- 平均最終壓力：7.1
- 主要失敗：欠租未解決（338 局）
- 成功結局：窮忙循環 85 局、自由生活 69 局、穩定生活 8 局

目前版本仍然偏難，且房租是最明確的主壓力來源。啟發式策略已能得到三種成功結局，沒有落入必輸或單一路線；實際數字仍需玩家測試後調整。

node scripts/balance-check.mjs
