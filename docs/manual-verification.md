# 人生好難 v3 驗證清單

## 手動驗證

- [ ] 360 × 640 viewport：開始遊戲後，日期、五個狀態、情境與 2～3 個行動都能直接操作，沒有水平捲動。
- [ ] 主畫面沒有摺疊控制、採取行動按鈕、睡覺按鈕或獨立事件視窗。
- [ ] 每個行動按鈕至少 56px 高，且直接顯示主要數值影響。
- [ ] 選擇行動後，中央區顯示結果與實際變化；「繼續」只負責前往下一時段。
- [ ] 早上、下午、晚上各選一次後，自動扣生活費、恢復睡眠並進入隔天。
- [ ] 點擊金錢、體力、壓力、技能、工作、特質或故障狀態，會開啟 bottom sheet 說明；關閉後焦點回到原按鈕。
- [ ] 有固定工作時，上班直接是該時段的一個選項，不會先出現出勤確認。
- [ ] 找工作成功後直接切換工作，不會再問是否接受。
- [ ] 同一份工作缺勤兩次後會失去或降級工作。
- [ ] 機車或電腦故障時，主畫面出現狀態 icon，且後續選項包含修理或 workaround。
- [ ] 第 7、14、21 天自動處理房租；第一次繳不出形成欠租，下一期仍未處理會結束遊戲。
- [ ] 設定中的重新開始需要二次確認。
- [ ] 第 21 天晚上結算後顯示單一主結局與簡短標籤。

## 驗證指令

```bash
node scripts/verify-gameplay.mjs
node scripts/verify-phone-travel.mjs
node scripts/balance-check.mjs
node scripts/verify-share-compat.mjs
node scripts/smoke-ui.mjs
```
