# 打工人生 MVP 驗證清單

## 手動驗證項目

- [ ] 開啟 [index.html](/Users/kan/Documents/hard-life/index.html) 後，首頁能顯示第 1 天、五個核心數值、目前工作、房租倒數與六個行動按鈕。
- [ ] 在 Lv.1 點擊「去打工」後，金錢增加 800、體力下降 25、心情下降 8、壓力上升 8，並且額外扣除每日生活費 150。
- [ ] 將狀態推到第 7、14、21、28 天時，會自動處理房租；若金錢不足，欠租次數會增加並套用心情與壓力懲罰。
- [ ] 體力低於 25 時進行「加班」，有機率額外觸發過勞懲罰。
- [ ] 技能提升後使用「找新工作」，成功時會依條件升到適合的工作等級，失敗時套用體力、心情、壓力懲罰。
- [ ] 事件觸發後，主畫面不允許再次點擊主要行動，直到事件選項被解掉。
- [ ] 自動事件會直接寫進每日結果區；有選項的事件會顯示事件標題、描述與按鈕。
- [ ] 金錢 <= -3000、體力 <= 0、心情 <= 0、壓力 >= 100、欠租 2 次時，會立刻進入對應失敗結局。
- [ ] 第 30 天完成後會只顯示一個最終結局，並提供重新開始按鈕。
- [ ] 點擊重新開始後，所有狀態回到預設值，重新回到第 1 天。

## 驗證指令

在專案根目錄執行：

```bash
node scripts/verify-gameplay.mjs
```

這個檢查會覆蓋預設狀態、回合流程、房租壓力、找新工作升級、事件解決與結局規則。
