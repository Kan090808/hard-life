# 打工人生 v2 驗證清單

## 手動驗證項目

- [ ] 開啟 [index.html](/Users/kan/Documents/hard-life/index.html) 後，首頁能顯示第 1 天、五個核心數值、工作、房租倒數、今日進度、睡醒預估與持續狀態區塊。
- [ ] 第 1 天點擊「學技能」後，當天不會立刻跳到第 2 天，且首頁的「今日進度」會變成 `今天已做 1 件事`。
- [ ] 在還沒做任何事時也可以直接點「睡覺」，並在隔天看到體力恢復、壓力下降。
- [ ] 點擊「睡覺」後，才會一次性扣除每日生活費與處理當天房租判定。
- [ ] 同一天連續兩次選同一個 action 時，第二次會顯示更高的體力代價、較低的正收益，且更容易觸發事件。
- [ ] 透過「社交拜訪」或事件拿到接案人脈後，「接案」會從不可用變成可用，且 UI 會顯示對應解鎖條件已滿足。
- [ ] 觸發「機車在路上出怪聲」並選擇延後維修後，首頁持續狀態會出現機車待修，之後做需要出門的行動會受到額外懲罰。
- [ ] 在機車待修狀態下使用「處理雜事」後，機車待修會被清除，相關懲罰也會停止。
- [ ] 有固定工作時，睡醒後會先跳出「今天要不要去上班」對話，做完這步才回到自由行動。
- [ ] 有多日案子時，睡醒並完成上班判定後，會先自動扣案子的每日體力成本，再回到自由行動。
- [ ] 體力很低或連續重行動後，會更容易遇到健康警訊類事件；事件結果會清楚說明是立即數值變化還是持續狀態。
- [ ] 在第 7、14、21、28 天結束當天時，房租會只被結算一次；若繳不出來，欠租次數與房東壓力狀態都會更新。
- [ ] 第 30 天完成後會只顯示一個最終結局，並提供重新開始按鈕。
- [ ] iPhone Safari：月底結算頁點圖片按鈕時，若可原生分享就會開分享面板；若不能原生分享，至少會開圖片預覽並可長按儲存。
- [ ] Android Chrome：月底結算頁點圖片按鈕時，至少能成功原生分享或下載圖片其中一種。
- [ ] 桌面 Chrome / Safari：月底結算頁的圖片按鈕文案會變成「下載圖片」或「開啟圖片」，且點擊後有可見結果；文字按鈕能分享或複製結果。
- [ ] 常見 in-app browser：若系統分享與剪貼簿不可用，文字按鈕仍會開手動複製視窗，不會靜默失敗。
- [ ] 在 insecure context 或模擬關閉 `isSecureContext` 時，文字按鈕會退回手動複製視窗，並顯示明確提示。

## 驗證指令

在專案根目錄執行：

```bash
node scripts/verify-gameplay.mjs
node scripts/balance-check.mjs
node scripts/verify-share-compat.mjs
```

第一個檢查覆蓋純體力制、睡覺恢復、重複 action 懲罰、房租壓力、出勤/跑案與結局規則。  
第二個檢查會用固定種子跑 500 局，快速看純體力制與重複 action 懲罰後的結局分布是否明顯失衡。  
第三個檢查會驗證分享能力判斷、按鈕文案、圖片／文字 fallback 順序，以及 `AbortError` 不會被當成失敗。
